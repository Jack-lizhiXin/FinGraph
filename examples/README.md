# 在同一张图上比较三种节点打分方法

新生可以用这个例子做第一次对照实验。有少量正常与异常标签时，加入邻居属性会怎样？只知道五个正常节点时，又能用什么打分？输入是手工构造的 24 个虚拟节点，运行时离线，无须安装第三方包。

## 运行

在仓库根目录执行以下命令，使用 Python 3.8 或更高版本。

```bash
python3 examples/node_baselines.py
```

脚本默认读取自身所在目录的两个 CSV。也可以从任意目录传入脚本的完整路径。更换数据或复核名额时可指定参数。

```bash
python3 examples/node_baselines.py --nodes examples/nodes.csv --edges examples/edges.csv --top-k 5
```

## 输入和评分时可见的信息

- `nodes.csv` 中，`activity_index` 是虚构的非负活跃度指标，`night_share` 是虚构的夜间活动占比。`node_id` 仅用于索引。固定切分包括 9 个训练节点、5 个无标注节点、10 个测试节点。二分类标签 0 表示正常、1 表示异常，未标注节点的标签留空。`normal_seed=1` 表示可以告知单类方法该节点正常。
- `edges.csv` 中，每行是一对有联系的虚拟节点。采用静态、无向、无自环的简单图，每条边只列一次。计算一阶邻居属性均值时使用全图，包含无标注和测试节点的输入属性。这是**直推式（transductive）节点打分**，假设预测时已经能看到整张图。研究未来交易预警时，需要另行规定预测时间并按当时可见的边及属性构图。
- 特征只包括本节点两项属性，或者再拼接两个一阶邻居属性均值。孤立节点用自身属性作为邻居均值的回退值。标签、切分与正常种子标记不进入特征。测试标签仅用来计算最后的指标。

| 方法 | 可用训练标签 | 对节点怎样打分 |
| --- | --- | --- |
| 双类监督，仅本节点属性 | 5 个正常、4 个异常 | 分别求两类训练中心。离正常中心越远、离异常中心越近，风险分越高。 |
| 双类监督，加邻居属性 | 同上 | 采用同一分类器，只增加一阶邻居属性均值，可直接观察结构输入的增量。 |
| 仅正常标签，加邻居属性 | 5 个正常种子 | 以正常种子为参照，按到其中心的标准化平方距离排序。其余节点仅提供图结构和输入属性。 |

双类方法的尺度参数用 9 个训练节点估计。单类方法的中心和尺度只用 5 个正常种子估计。遇到常量特征时，尺度取 1。这个单类距离基线没有复现某篇已发表的半监督算法。

## 默认结果与讨论

| 方法 | AP | P@3 |
| --- | ---: | ---: |
| 双类监督，仅本节点属性 | 0.810 | 0.667 |
| 双类监督，加邻居属性 | 0.917 | 0.667 |
| 仅正常标签，加邻居属性 | 0.917 | 0.667 |

测试集含 3 个虚拟异常节点。AP 是按不同分数阈值计算的平均精确率，同分节点整组计入。P@3 表示排名最靠前的三个节点中异常所占比例。如果分数相同的一组跨过名额边界，按该组内随机排序的期望命中数计算。在本样例中，加邻居信息后双类方法的 AP 提升，但复核前三个仍命中两个。后两行的指标相同，其训练时可见的标签不同。

可以在 CSV 的副本中删除与某个测试节点相连的边，保持切分和标签不变，比较 AP 与 P@3 如何变化，再讨论预测时是否真的能获得这些关系。这些数字只用于核对脚本和理解指标。金融数据上的检测能力需另用对应的数据、标签和时间切分验证。
