# 论文精读卡 · 填入简称

| 项目 | 记录 |
| --- | --- |
| 论文 ID / 原文 | 填书目 ID、原文链接和正式版本 |
| 问题与主分支 | 用一句话写出要解决的问题 |
| 数据和判断对象 | 哪种图？一个预测值对应谁？ |
| 标签设定 | 多少已标正例、已标负例、未标注样本？哪些样本参与损失、传播或采样？缺失之处注明“原文未披露” |
| 本次汇报人 / 复核人 / 日期 | 填实际参与者 |

## 原文证明了什么

挑一项最关键的结果。写明数据集、对照方法、切分、指标和原文表格或页码。用自己的话解释该结果，注明证据适用的范围。

## 与树上另一篇的关系

链接一篇可比论文。比较二者使用的标签和测试对象，指出一项重要的相同点或差异。

## 下一个实验

提出一个能够被实验否定的判断。写出最小对照、固定条件和什么结果会改变判断。
