# 动态图异常检测方法的研究与应用：面向金融交易网络的视角

综述写作底稿，检索边界更新至 2026-11-20。下面的摘要与引言供作者组修改。检索方案、待检验命题和图表设计均为预先规划，入选数量、效应量和跨模型优劣需在双人筛选与证据复核后填写。

## 摘要初稿

同一条转账可以触发交易审核，也可以作为发现可疑账户或资金网络的证据。预测单位的改变会同时改变可用历史、监督信号和告警的核验方式。本文围绕一个具体问题组织动态图异常检测研究：在交易发生、特征到达与调查结果返回的不同时间点，模型能够凭借哪些证据发现哪一类异常？我们提出按检测对象、时间表示、监督来源和部署决策交叉编码文献，将各项实验还原为可核查的预测协议。在金融应用中，重点考察历史邻域的可见范围、正常与未标注样本的划分、合成资金流与真实调查标签的差异，以及固定复核预算下的事件命中率。综述同时讨论统计流式方法、时序表示学习、动态图神经网络和异常子图搜索，设计跨时间及跨来源的验证方案，为方法选择和后续实证研究建立共同的比较基础。

**关键词**　动态图异常检测，交易网络，反洗钱，金融欺诈，时间泄漏，告警评估

## 引言初稿

一笔转账在上午九点进入清算系统时，付款者此前的交易可能已经可查，收款者当天稍后的邻居尚未出现，调查人员的结论则可能在数周后返回。研究者若用整日图计算双方的度数，或把最终结案标签回填到当日训练集，离线得分就使用了当时无法取得的证据。另一个差异常被数据表的行列结构掩盖。Elliptic 将比特币交易建为节点，Elliptic2 提供候选交易子图与相应标签，TransXion 把账户间的交易表示为边。三种模型即使都输出介于零与一之间的分数，也分别在给交易、候选子图或网络中的实体与关系排序。评估时必须先回答谁会收到什么告警，其后才能定义一次命中。[Elliptic](https://arxiv.org/abs/1908.02591) · [Elliptic2](https://arxiv.org/abs/2404.19109) · [TransXion](https://doi.org/10.1145/3770855.3817550)

一般图异常检测文献已经给出了异常对象、方法家族和解释方式的系统分类。动态图综述进一步归纳了统计、矩阵、概率与深度方法。近年的金融综述已研究时空表示、循环资金流、数据泄漏、告警阈值和预算指标，本综述的切入点因此落在每项实验的可审计条件上。研究者能否从论文或代码重建打分时刻的图？只有正常标签、少量正负标签以及由模拟器生成完整真值的研究，分别能支持什么结论？当一个案件对应多笔转账，按边排序得到的前十条告警又能支持多少次独立调查？本文据此连接模型的时间假设、标签的来历与评估结果的使用边界。[Akoglu 等](https://arxiv.org/abs/1404.4679) · [Ma 等](https://doi.org/10.1109/TKDE.2021.3118815) · [Ekle 与 Eberle](https://doi.org/10.1145/3669906) · [Lai 等](https://doi.org/10.1007/s44163-026-02506-3) · [Ale 等](https://doi.org/10.62411/jcta.18143)

金融数据尤其适合检验这些界限。模拟账本能给出生成机制定义的全部异常，真实调查数据则只覆盖获选核查并留下结果的样本。在模拟器上验证对指定转账模式的灵敏度，和在银行告警流上检验有限复核能力下的命中率，回答的是不同问题。一般动态图基准提供了受控注入、自然异常和简单基线，可用来定位得分究竟来自图结构、重复边还是注入规则。只有检测对象、切分、标签和指标都能对齐的设置，才进入同组比较。[IBM AMLWorld](https://research.ibm.com/publications/realistic-synthetic-financial-transactions-for-anti-money-laundering-models) · [银行交易实证](https://doi.org/10.1016/j.jfds.2025.100175) · [BAG](https://doi.org/10.1609/aaai.v40i17.38510) · [DyGADBench](https://doi.org/10.1145/3770855.3817594)

## 拟回答的研究问题

| 编号 | 可以从论文中检验的问题 | 正文应给出的结果 |
|---|---|---|
| RQ1 | 异常由哪个实体、事件或结构承载？时间表示保留了哪些先后关系？ | 交易节点、账户节点、带时间边、候选子图、事件流或整图的定义与映射图。分别标记带时间特征的静态预测、离散快照和连续事件预测。 |
| RQ2 | 各方法依赖哪类标签和历史？得分如何用于在线检测？ | 方法矩阵注明打分单位、训练与调参信号、可见时间窗、内存更新顺序、是否需重训及朴素基线。 |
| RQ3 | 模型提升在何种测试条件下成立？能否区分对生成规则的拟合与对自然异常的识别？ | 按数据真值、时间切分、负例规则和评估单位分层，列出可同表比较的实验及其边界。 |
| RQ4 | 当金融机构只能审查有限数量线索，哪些证据支持迁移或部署？ | 逐期账户或案件命中、发现延迟、告警工作量与标签成熟度。为缺失这一信息的研究保留“未报告”。 |

## 方法知识树的交叉索引

保留既有论文树中的主归属。每项实验另行填写以下横向维度，同一论文可具有多个实验记录。

| 维度 | 编码与比较要点 |
|---|---|
| 对象和决策 | 账户风险、交易风险、关系异常、给定候选团伙评分、从全图发现团伙、整体状态变更。记录“边→账户→案件”的归并规则和一对多关系。 |
| 时间表示 | 静态对照、固定快照、滑窗、离散事件、连续时间。分别记录窗口宽度、打分前是否见到当前交易、先评分还是先更新记忆、同时间戳事件的处理。 |
| 证据和方法 | 边计数与突发、结构变化与时序模体、预测/重构残差、时间邻域或记忆网络、时空对比学习、生成/密度估计、子图搜索。记录训练目标如何转成异常分数。 |
| 训练和调参 | 完整或部分双类标签、仅可信正常样本、仅阳性与未标注样本、自监督、无标签、模拟/注入训练、跨图零样本。逐列保存训练、选阈、测试标签。 |
| 来源和可迁移性 | 真实银行资金流、链上交易、金融关系代理图、合成账本、非金融动态图。资金流模式的实验主张须查证边的业务含义及标签产生方式。 |
| 成本与解释 | 告警量、每期复核预算、检测延迟、训练与在线更新代价。解释可为历史特征、邻域或资金流路径，记录是否有专家或人工调查验证。 |
