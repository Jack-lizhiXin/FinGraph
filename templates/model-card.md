# 模型卡 · 填入方法名称

| 项目 | 记录 |
| --- | --- |
| 论文 ID / 原文 | 链接论文索引中的条目 |
| 当前状态 | 候选（文献已收录） / 已跑通 / 已复核，选一项 |
| 责任人 / 复核人 / 最近更新 | 记录参与者及日期 |
| 解决的问题与比较对象 | 预测账户、交易还是子图？与谁比较？组内为何要运行它？ |
| 输入 / 输出 | 图、关系类型、时间戳、特征及标签条件。输出是一对象一分数还是一时间窗一告警 |
| 代码来源 / 版本 / 许可 | 作者代码链接或组内重实现。记录提交号、版本及许可信息 |
| 数据版本与评测协议 | 链接适用的评测协议及可复核的数据版本，说明使用范围 |
| 运行环境 | Python/依赖版本、CPU/GPU、内存 |
| 运行命令与随机种子 | 精确到足以让另一位同学重跑 |
