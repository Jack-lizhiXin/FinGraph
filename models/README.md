# 模型卡

从[论文索引](../catalog/README.md)进入每个关联方法的模型卡。卡片分列原论文结果、组内首次运行和独立复核，读者可以据此判断手头是否已有可用实现。

### 首轮候选方法

| 模型卡 | 训练标签 | 第一次复现要回答的问题 |
| --- | --- | --- |
| [BWGNN](bwgnn.md) | 既有正常也有异常标签 | 在相同输入与标签预算下，使用图上不同频段的信息较简单基线能改善多少？ |
| [GGAD](ggad.md) | 少量可信正常标签 | 用正常种子生成伪异常，是否优于按偏离正常样本的距离打分？ |
| [CR-Aug](cr-aug.md) | 少量可信正常标签 | 固定伪异常总量，依据社区差异采样是否比全图统一采样更有帮助？ |

### 如何判断模型进展

| 状态 | 可以如何使用 |
| --- | --- |
| 候选（文献已收录） | 在组会上讨论研究价值，确认代码、数据和下一个最小实验。 |
| 已跑通 | 按卡片的具体数据、命令和版本重复组内已有运行。 |
| 已复核 | 在已登记的协议和数据范围内作横向比较，用记录的差异解释复现偏差。 |

复制[模型卡模板](../templates/model-card.md)，保存为 `models/<id>.md`。在该论文的 `model` 字段登记路径，并链接一份具体的[评测协议](../protocols/README.md)。
