# 评测协议 · 填入数据集与版本

| 项目 | 约定及依据 |
| --- | --- |
| 协议 ID / 维护人 / 日期 | 填写稳定标识与最近修订日期 |
| 数据和图版本 | 原始来源与许可、版本号或校验值、实际可用字段、预处理代码版本 |
| 样本单位与标签 | 账户、交易或子图。标签来源、定义、确认时点。独立记录未标注样本 |
| 时间与图可见范围 | 记录事件发生、特征可用、标签可用的时间。写明预测时允许使用哪些边与邻居 |
| 切分 | 训练、验证、测试的日期或索引。记录每段正、负、未知数量及重复实体。按题目选择时间外推、主体外推或原文随机协议 |
| 标签预算 | 原始可用标签、每类实际用于训练的标签数、已标样本的抽取规则、未标注池的组成与用途 |
| 基线与公平性 | 同一份切分与特征版本。固定可见数据和调参预算。说明训练时是否可看到测试图结构 |
| 规模与资源 | 节点数、边数、关系数、硬件。测延迟时说明批量、预处理和计时边界 |
| 输出和复核 | 随机种子、配置文件、数据切分与指标脚本版本、日志、复核人 |

## 按场景选择评价指标

对罕见正例检测，记录标注测试集中的正例比例，写清 AP 的计算方式。若用梯形积分计算 PR-AUC，按该名称单列。给定每个时间窗可复核的告警数 K，可报告 Precision@K 与已知正例上的 Recall@K，列出 K、分母及其覆盖范围。只有具备独立真值时，才据此估计包括未标注对象在内的总体效果。

## 阻断数据泄漏

- 时间外推时，以预测时点截取交易边、聚合特征、邻居索引和可用标签。涉及金额窗口、账户画像或社区划分时，逐项说明其观察窗口。
- 只用训练部分拟合标准化、重采样或类权重。用验证集选模型和阈值。预先冻结测试切分，记录多次运行的种子和离散程度。
- 复现原作者的传导式协议时注明哪些无标签节点与边可见。部署模拟另建时间切分协议，并用单独结果表呈现。
- 合成数据需记录生成器版本、规则、随机种子及标签构造。实体或模式外推时，按对应策略隔离训练与测试。结论注明“合成条件下”。
