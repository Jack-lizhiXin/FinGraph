# BAD：只凭过去的交易对象，能否识别不寻常的下一次交互？

一次事件含来源、去向和时间。BAD 把去向的身份嵌入与来源的近期邻居作交叉注意，学习这条边与刚发生过的互动是否相容。随后以归一化流拟合常态交互表示的密度，用似然评价偏离程度。该设计不依赖交易金额或用户画像。[IJCAI 原文，§4](https://ijcai.org/proceedings/2026/0322.pdf)

**评测语义。** 表1的 Wikipedia 与 Reddit 关联后续用户状态；Bitcoin-Alpha 和 Bitcoin-OTC 是交易者相互评分形成的信任网络。算法在交互时刻打分，评价用的是由这些数据构成的动态标签。不能把负面评价解释为链上非法付款。[§5.1、表1](https://ijcai.org/proceedings/2026/0322.pdf)

**怎样比较。** 作者把按时间排列的最后15%交互留作测试，表2并列报告 AUC 与 AP。§5.2 说明，部分表示学习基线先做链路预测、再用标注训练分类器，而规则基线无需拟合。直接按表排序会掩盖监督信息不一致。使用账户身份嵌入时还要区分旧账户和首次出现账户。[§5.1–5.3、表2、图2](https://ijcai.org/proceedings/2026/0322.pdf)

**复现问题。** 用同一批历史邻居，比较最近往来次数、局部频率概率与 BAD，固定告警预算。将金额等额外属性留作单独实验，验证无属性结构信号比频率多找出了哪些异常。
