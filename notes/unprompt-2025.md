# UNPrompt — 一个模型能否迁移至新图？

- **正式出处**：[IJCAI 2025 主会全文](https://ijcai.org/proceedings/2025/359)，DOI `10.24963/ijcai.2025/359`；[作者代码](https://github.com/mala-lab/UNPrompt)。定位 §3.2–§3.5、§5 / Table 1、Table 3。
- **关键问题：** 当一家新机构几乎没有已标注的异常交易时，在其他图中学到的“邻域属性可预测性”能否迁移？论文研究的是**通用异常节点**的零样本迁移，不能直接等同银行边级交易洗钱识别。
- **训练与测试：** 在源图学习（原文用 Facebook 作为训练源），目标图无标签且不再训练；通过维度投影＋逐坐标归一化统一属性空间，用邻域提示衡量属性预测难度。这里的“零样本”不等于从未利用任何源图标签。
- **证据：** 原文 §5 Table 1 源图 Facebook，分别测试 7 个其他节点图，报告 AUROC 和 AUPRC；§5 Table 3 则是同图无监督对照，属于不同协议。
- **我们的空白：** 在跨银行账户图/合成交易边上是否仍然有效？流式时是否允许使用整个测试图的 SVD 统计？需要新实验，不引用本文结果作金融证据。
