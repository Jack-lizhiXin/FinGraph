# 孪生图网络：为市场关系的结构突变定义一个监测对象

这里的一个样本是整张图快照。模型比较当前图与短期历史中的图，估计网络是否进入另一种状态。股票间的边表示收益相关性，与账户转账边有不同的经济含义。[论文 §3、§4.4.1](https://doi.org/10.1007/s10994-023-06405-x)

**怎样获得相似性监督。** 孪生图网络学习两张图是否属于同一阶段，并通过排序池化捕捉局部结构变动。训练时可抽取跨度较大的图对，验证时则用窗口内图对逼近真实检测条件。若训练阶段缺少变点真值，作者先用光谱算法在历史段估计变点，再据此生成配对标签。[§3.4、§4.4.1](https://doi.org/10.1007/s10994-023-06405-x)

**金融案例中容易忽视的步骤。** 论文由月内股票收益计算相关矩阵，将极高或极低相关保留下来，得到244张快照。真实市场阶段没有变点真值。尤其值得注意的是，原文采用全体快照求相关阈值和节点属性标准化参数。若要宣称可以上线运行，须改为只用训练期估计或滚动更新，然后重新评价。[§4.4.1，输入图构造与属性标准化](https://doi.org/10.1007/s10994-023-06405-x)

**复现问题。** 在模拟图植入已知结构突变，比较检测延迟和指定容忍窗口下的 F1。真实交易图则记录警报触发的日期、当期采集范围和结算日效应；在获得独立事件证据前，将结果作为待解释变化。
