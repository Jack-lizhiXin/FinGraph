# Dynamic Neighborhood Modeling via Node-Subgraph Contrastive Learning for Graph-Based Fraud Detection

Zhizhi Yu, Chundong Liang, Xinglong Chang, Dongxiao He, Di Jin and Jianguo Wei · AAAI · Technical Track 2025 · 核对日期 2026-11-20

| 读前先确认 | 本文设定 |
| --- | --- |
| 预测对象 | 节点（按数据集区分账户、用户或评论） |
| 标签条件 | 双类标签及节点—子图对比辅助信号 |
| 研究场景 | 微博、电商评论及金融账户图 |

原实验覆盖 Weibo、Amazon、YelpChi、T-Finance；主实验训练／验证／测试比例为 4∶2∶4，并报告重复运行结果。可把固定邻居、概率驱动邻居以及去掉对比损失三组放在同一切分上，核查变化来自邻居选择还是辅助目标。
