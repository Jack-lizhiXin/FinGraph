# VUS｜让事件时间边界的不确定性进入评测

**研究问题。** 当真值标成区间、模型输出逐点连续分数时，轻微时间偏移会如何影响排序评价？作者通过改变允许匹配的邻近范围，对一系列 ROC 或 PR 曲线进行整合。

**读正文。** 第 5.4 节及图 9–10 分别考察评分发生时间偏移、增加噪声等扰动后的指标行为。阅读曲线时应同时记录异常比例、序列长度和容忍窗口。作者研究指标的性质，论文没有对反洗钱模型开展比较。

**与 point adjustment 的区别。** Kim 等人的问题是一次命中可以重写整段逐点预测；本篇展示不同容忍距离和评分阈值下的评价。对于调查窗口，容忍距离必须能解释成具体业务允许的提前量或延迟，回溯发现与及时拦截的收益也要分开。

**可执行检查。** 用同一批带案件起止时间的数据，逐步平移预测分数，画出逐点 AP、VUS-PR、案件首次告警延迟三条变化曲线。在有时限要求的交易处置任务上单独给出时限内召回率。公开数据没有案件边界时，报告可观测范围并保留逐点结果。
