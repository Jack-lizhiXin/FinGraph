# IBM AMLWorld — 评价合成 AML 结果时不能跳过的数据许可

- **出处：** [NeurIPS 2023 Datasets & Benchmarks 对应作者资源](https://github.com/IBM/AML-Data)。请从官方 README 和数据许可文件核对版本与使用条件。
- **核心差异：** 账户作为节点、资金转账作为边，洗钱模式由模拟机制产生，因此是真值可控的训练/评测数据，而不是银行执法核实后的真实标注。
- **许可：** **数据遵从 CDLA-Sharing-1.0**，IBM GitHub 项目代码采用 **Apache-2.0**；这两者不可互相替代。FinGraph 仅保存链接/统计/模型脚本，不导入原始流水或数据压缩包。
- **复现关键：** 固定 HI/LI 配置、样本版本、时间切分、模式级划分，再分清交易边分类与账户聚合分类。跨同种生成器与跨生成器差异很大，不能以其中一种推断真实世界效果。
