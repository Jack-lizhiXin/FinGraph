# 检索、筛选和证据提取口径

**版本边界。** 本版用五个发表年度 2022–2026，末年截至 2026-11-20。早于 2022 年的奠基或协议参照保留在全库书目，单独计数。遇到预印本与会议或期刊版本，优先保留正式版本；仅有预印本的记录须保留其身份。线上先发与卷期跨年的论文须记录所用版本。年份按条目采用版本计，不从引用次数推断新旧。

[本期冻结名单](scope.json)记录检索截止日、起始年度和实际筛入的论文 ID。以后只给总书目增添论文时，本期队列保持可追溯。扩展综述窗口时，在同一个 PR 更新截止日、筛入名单和工作区统计，再运行索引生成命令。

**入选候选。** 论文至少回答一项问题：检测动态图中的异常、检测金融实体或资金关系风险、提供可重用的图异常方法对照、检验时序评测或提供相关数据与综述。时间序列指标和链接预测研究仅在能具体解释图评测选择时收录。工作按标题、DOI 和版本人工对照，再对规范化标题、来源 URL、ID 和 DOI 做程序查重。仓库内两个团队旧包共享条目只算一次。

**入选核心。** 每篇须填入与综述问题的关系、方法、时间表示或切分、评分对象、标签来源、金融适用范围、局限和证据位置。直接金融实证、通用动态检测、静态监督对照和评测基础分别标出。核心表示对某一综述论证有明确作用；例如，能揭示随机负采样改变模型排序的基准可入核心，但不能据此声称模型识别了洗钱交易。

**证据层级。** 在矩阵中按行登记正文方法／表图、作者摘要、官方题录或已有模型卡的核查范围。只有能定位实验设置和结果的正文才用于录入可比较数字。正文表格的数字另标明是作者报告还是团队复现。缺少的标签到达时刻、案件来源、时间切分或代码版本明记“待核”，后续 PR 可只补一个字段并附原出处。

**进入投稿版前。** 该库是按问题定向检索的范围综述工作集。当前日志保留实际检索方向、来源和部分排除原因。投稿前应冻结数据库导出、完整检索式和检索时间，开展双人独立筛选，保留冲突裁决表并追溯前向与后向引用。只有可追溯到原始导出的检索和排除数才用于绘制 PRISMA 流程图。

| 后续提取项目 | 一条结果必须能回答什么 |
| --- | --- |
| 时间可见性 | 评分时哪些交易、邻居、风险标签及标准化参数已经可见？同一时间戳如何排序？ |
| 监督条件 | 源域与目标域分别给了哪些标签？未知样本、负采样关系和已核正常分别如何定义？ |
| 评测单位 | 是节点、已观察交易边、采样非边、候选子图、全图发现，还是时间窗口？ |
| 可比结果 | 指标、基率、划分、告警预算、重复实体和测试时更新是否一致？研究是合成、链上、平台关系还是银行流水？ |
| 更新与署名 | 贡献者在 PR 中给出补录来源、链接、提取范围和复核者；累积争议保留在 PR。 |

从[综述工作区](README.md)可打开各方向的检索记录。运行 `python3 scripts/catalog.py` 和 `python3 scripts/survey.py` 会从同一份 JSON 更新可读索引及方法矩阵。提交前给两个命令加上 `--check` 检查结果。
