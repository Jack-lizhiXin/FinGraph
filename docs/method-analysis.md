# 五篇图欺诈检测论文的实验条件与复现价值

核对日期为 2026 年 11 月 20 日。本次选取 AAAI、IJCAI 和 KDD 的五篇方法论文，补充现有 FinGraph 书目中的 BWGNN、GGAD、RHO、CR-Aug 等工作。共同的问题是：同一笔交易或同一个账户的特征给定后，利用邻居、已确认的历史欺诈标签或其他图上的经验，还能多找出哪些疑点？

## 哪些结果适合放进同一张表

SEC-GFD 与 NAAST-GNN 共享多个公开节点数据集，有适合复核的谱域方法差异。先登记是否合并多种关系、异常与正常的有标训练节点数、验证集选参方式、随机种子与指标实现；再用同一份掩码比较逐节点预测。DCL-GFD 可加入相同节点任务，独立测量自适应邻域相对固定邻域的变化。MimbFD 可在拥有多关系边且允许使用训练标签传播的设置下进入这组比较。

AnomalyGFM 的评估表应另设“源图已使用的标签、目标图可用标签”两栏。对同一个预训练模型，分别给目标图零标签和相同数目的已知正常标签，可以测量提示调优的贡献。若源图和目标图可能来自同一平台，还要核查实体、时间段和采样范围是否重叠。

以上研究中的同一“节点”可代表评论、用户或金融账户。在 Elliptic 中，节点代表一笔交易；在 TransXion 的原始任务中，一笔交易对应一条边。若把模型迁移到交易数据，先登记评分单位、评分当时可见的前序交易及标签确认时间，再发布指标。预测粒度、标签预算或时间边界不同的数值分别报告。

## 三项可在学生组会上验收的假设

1. **自适应邻居是否能降低误报？** 选择同一个带双类标签的节点数据集，固定数据切分、编码器规模和训练标签预算，比较属性基线、固定邻居以及按预测概率选择邻居。在相同人工复核名额下统计多找到多少已知异常，同时列出被挤出名单的正常样本。再打乱邻居分组，检查收益是否确实来自分组机制。
2. **模型能否发现离已知异常较远的节点？** 在多关系图上只开放训练期已确认标签，以每个测试点距训练期最近已知异常的距离分组。分别记录各组样本量、阳性率、召回和命中数，比较 MimbFD 与采用相同关系类型的普通聚合器。无可达异常的节点单列；计算距离时不能使用测试标签或未来的边。
3. **少量正常标签的收益来自哪里？** 对同一个 AnomalyGFM 源模型冻结权重和测试节点，设“目标域零标签”和“给定少量正常样本用于适配”两组，多次更换正常样本种子。将两种设定按相同告警名额比较，再单列同目标预算但未使用外部训练图的基线。若某一批正常种子带来的收益远高于其他批次，优先检查其社区与业务群体覆盖。

本次完成论文证据梳理。上述实验是拟执行的组内验证，数值留待执行后归档。
