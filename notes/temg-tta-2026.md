# TEMG-TTA｜当区块链异常地址检测器换一张图

**问题。** 源事件中有已知异常地址，目标事件没有训练标签。面对交易结构与异常基率同时变化，能否利用目标图本身适应检测器？输出是地址分数，交易提供带方向、时间戳的边。

**方法和信息边界。** 第 3.1–3.3 节将三节点有向时序模体并入表示，在带标签源图上预训练。第 3.4 节在无标签目标图上进行教师与学生的一致性更新，对学生施加随机删边，用指数滑动平均更新教师。实验允许适应期间观察目标图。同一天逐笔处理交易时，能否看到后续边，是单独的部署问题。

**原文结果怎么读。** 表 3 固定 GCN 和 Upbit 源图，迁到 Cryptopia 的 AUC-PRC 从 0.2628 增至 0.4274，迁到 Trace 从 0.0378 增至 0.0386。表 1 的异常比例从 PlusToken 的 80.34% 到 Trace 的 0.16%。这两组结果说明报告迁移方向、目标基率和绝对差值有多重要。第 4.3–4.4 节的模体案例与消融支持继续分离模体特征和目标域适应的贡献。

**进入综述的方式。** 放进“跨事件迁移／未标注目标图可见”一格。可以与冻结的同一骨干比较，用按日截断的目标交易图重做适应，分别记录每个源–目标对的 PR 曲线和复核预算下的命中。Trace 的访问条件影响独立验证。以上数值均为作者报告。
