# BWGNN · 图上不同频段能否改善异常节点识别？

**当前状态**　候选（文献已收录）  
**建卡日期**　2026-11-20。运行人、复核人由首次周会认领。

Jianheng Tang、Jiajin Li、Ziqi Gao、Jia Li 在 ICML 2022 提出 BWGNN。它用一组图上的 Beta 小波滤波器提取节点属性在邻域中不同尺度的变化，并学习哪些信号有助于识别异常。输入为静态图、节点属性及训练集中的正常和异常标签，输出为每个节点的异常分数。论文分别考察标签较充分和稀少时的表现。即使用较少标签，该方法仍需要两类标注。[论文](https://proceedings.mlr.press/v162/tang22b.html) · [作者代码](https://github.com/squareRoot3/Rethinking-Anomaly-Detection)

## 第一次复现拟做什么

1. 在作者代码中记录提交号、数据版本、软件依赖与运行设备。作者列出的版本有 PyTorch 1.9.0 和 DGL 0.8.1。拟从 Amazon 评论关系图入手，按原文表 2 的 Amazon 40% 训练标签设置，使用同质图版本。
2. 数据与环境准备后，在作者仓库根目录执行下方命令。登记实际使用的随机种子、三组切分中两类标签的数量、Macro-F1 与 ROC-AUC。先核对模型能否得到有限数值和逐节点分数，再检查与原文统计口径的差异。表 2 为多次运行的均值，单次运行只作流程核对。
3. 进入金融数据试验时，另按 [Elliptic 节点试验方案](../protocols/elliptic-node-pilot.md) 的双类标签设置适配数据。先用协议规定的两个上游特征跑逻辑回归。若希望加入 BWGNN，应记录每个滤波器可见的边、传播方向和跳数，通过“追加下游交易后既有节点分数不变”的检查。原始实现若需完整双向图，可单列完整快照实验，使用同一快照作对照。

```bash
python main.py --dataset amazon --train_ratio 0.4 --hid_dim 64 --order 2 --homo 1 --epoch 100 --run 1
```

**验收证据**　另一位同学可从提交号、环境、数据校验值、切分记录和命令找到同一份运行日志。首次运行记录和独立复核结果均待补充。复核时再登记数值、波动范围和主要误差来源。

**适用边界**　Amazon 上学习到的是评论关系中的节点差异。迁移到链上交易图时要重新判断交易之间的边能否在评分时观察到，以及方向和图粒度改变后滤波是否仍有增益。
