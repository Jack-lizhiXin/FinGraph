# 新生的四次入门阅读

两周内按下表完成。时间为建议，每次带着最后一栏的产物参加讨论；有图学习背景的同学可直接从第二次开始。

| 次序 | 先读什么 | 动手回答什么 |
| --- | --- | --- |
| 第一次 · 60 分钟 | [Qiao 等的综述](../catalog/README.md#p-survey-qiao) 及 [DGraph](../catalog/README.md#p-dgraph) | 用一幅草图标出节点、边和标签，再用一句话写出“模型最终给谁打分”。说明按联系人建边是否等于按转账建边。 |
| 第二次 · 60–90 分钟 | [GADBench](../catalog/README.md#p-gadbench) 与 [BWGNN](../models/bwgnn.md) | 跑[教学例](../examples/README.md)，说明为什么 AP 改善、前三个名额命中数仍可能相同。提出一个便宜的非图对照。 |
| 第三次 · 90 分钟 | [GGAD](../models/ggad.md)、[CR-Aug 精读卡](../notes/cr-aug.md) 及 [RHO](../catalog/README.md#p-rho) | 对齐正常标签掩码，各写出一种提高检出率的机制和一种可能的误报来源。形成一张两至三篇比较表。 |
| 第四次 · 60 分钟 | [Elliptic](../catalog/README.md#p-elliptic)、[TransXion](../catalog/README.md#p-transxion) 与 [评测协议](../protocols/elliptic-node-pilot.md) | 找出两项最易混用的口径：交易作为节点或边、未知或已知正常。提出一个能在下一周完成的验证，按[周会模板](../templates/weekly.md)登记。 |

愿意继续深入的同学可阅读 [Nature 金融虐待研究](../catalog/README.md#p-nature-abuse)，讨论若观察期截止在客户披露之前，哪些事实仍然可用；再阅读 [DNB 银行研究](../catalog/README.md#p-dnb-aml)，辨析模型识别的是被调查对象还是有定论的案件。
