# 用 Elliptic 原始 CSV 运行两条基线

此入口实现[首轮交易节点协议](../../protocols/elliptic-node-pilot.md)。一条路线用正常与异常标签训练逻辑回归，另一条只用已知正常节点拟合中位数和绝对偏差。两个模型均输出测试段每笔交易的连续分数。当前验证使用临时构造的合成文件，原始 Elliptic 数据上的性能待运行后登记。

## 准备数据和运行

从[作者发布页](https://www.kaggle.com/datasets/ellipticco/elliptic-data-set)自行取得并解压原始 Elliptic Bitcoin 数据。将 `--data` 指向直接包含下列文件的目录。

| 文件 | 读取字段 |
| --- | --- |
| `elliptic_txs_features.csv` | 原始文件无表头。第一列为交易 ID，第二列为时间步。其余发布版属性不参与本协议。 |
| `elliptic_txs_edgelist.csv` | 表头为 `txId1,txId2`，分别表示前序交易和接收其输出的交易。重复交易对只计一个前序，重复数写入清单。 |
| `elliptic_txs_classes.csv` | 表头为 `txId,class`。1 为 illicit，2 为 licit，unknown 保持未知。按完整整数 ID 连接三表，不依赖文件中的行顺序。 |

以下命令从 FinGraph 仓库根目录运行。把示例数据路径换成本机路径。已验证环境为 Python 3.12、NumPy 2.3.5、scikit-learn 1.8.0。数据和输出目录可置于当前仓库之外。每次实验指定一个新输出目录。

```bash
python3 -m pip install -r pilots/elliptic/requirements.txt
python3 pilots/elliptic/run.py --data /path/to/elliptic_bitcoin_dataset --output ../elliptic-run-01
```

仅运行一条路线时添加 `--model supervised` 或 `--model normal-only`。运行合成夹具的自检可执行 `python3 -B pilots/elliptic/test_protocol.py`。该检查在临时目录生成三份小 CSV，覆盖三段时间、未知标签、并列分数、没有正例或候选的时间步、已存在的输出目录，以及为已评分交易追加下游交易后的分数稳定性。

## 预先固定的选择

- 拟合段为 1–30 步，验证段为 31–39 步，测试段为 40–49 步。本轮两种模型均固定参数，只记录验证段样本数。脚本不根据验证或测试成绩选模型、早停或调阈值。输入只使用两个由至多两跳入边计算的结构特征。
- 每步复核名额为 20。并列者按数值型原始交易 ID 升序排列。已标样本上的 AP 按各个不同分数阈值计算。已标候选池和全量候选池分别生成名单。
- 测试标签只传入评价函数。逻辑回归拟合函数仅接收双类训练行及标签，正常距离模型拟合函数仅接收正常训练行。两条路线打分的交易 ID 一致。
- 数据载入时检查节点、边和标签对齐，拒绝自环、跨时间步的边、缺失标签记录、重复或非规范交易 ID。原始数据若更新，请比较源文件哈希，再判断是否能与之前运行比较。

## 输出和复查

| 文件 | 可以复查什么 |
| --- | --- |
| `manifest.json` | 完成标记。列出协议版本、脚本和三份输入的 SHA-256、其他输出的 SHA-256、依赖版本、切分、特征与名额。 |
| `step_counts.csv` | 49 个时间步的标签计数、缺少前序交易的节点数与比例。空时间步也保留。 |
| `masks_features.csv` | 各笔交易的切分、发布标签是否已知、两条路线的拟合资格、两个结构特征。可按模型复核实际拟合的 ID。 |
| `models.json` | 实际模型设置、标准化参数、回归系数，以及正常样本中位数和原始中位绝对偏差。 |
| `scores.csv` | 测试段全部交易的时间步、模型和原精度分数。与本次运行清单配合，可定位模型版本。 |
| `alerts.csv` | 每步两种候选池的前 20 笔或实际可用数、名次和原始类别。 |
| `metrics.csv` | 已标样本 AP、已标榜单命中数和精确率、全量榜单已标非法／合法／未知笔数、命中率上下界、标签覆盖率及榜内已标样本命中率。`pooled` 行使用合并测试样本计算 AP，其余名额指标先跨步累加笔数再求比。 |

分母为零的指标留空，`ap_status=no_known_positive` 表示缺少可评正例。可先挑一个时间步，对照告警名单手工汇总 p 笔已标非法、l 笔已标合法、u 笔未知，以 (p+l+u) 为分母核实精确率下界和上界。对外交流时可使用汇总指标及其口径，逐笔记录在持有相应数据权限的环境中复核。
